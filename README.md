# Посмотри в окно

Проектная работа по курсу «Веб-разработчик» от Яндекс Практикума.

## Описание проекта

«Посмотри в окно» — это интерактивное веб-приложение, которое позволяет пользователям искать и просматривать видео с видами из окон в разных городах в разное время суток. Проект демонстрирует навыки адаптивной и семантической верстки, а также стилизации сложных интерактивных элементов без использования фреймворков.

## Функциональность

*   Поиск видео по названию города.
*   Фильтрация по времени суток (утро, день, ночь).
*   Переключение текущего видео по клику на карточку из списка.
*   Подгрузка дополнительных карточек по кнопке «Показать ещё».
*   Отображение прелоадеров во время загрузки данных.
*   Отображение сообщения об ошибке, если видео не найдены.

## Технологии

*   **HTML5** (семантическая разметка, теги `<template>` для шаблонизации).
*   **CSS3** (Flexbox для лейаута, кастомные чекбоксы, состояния `:hover`, `:active`, `:focus-visible`, кастомный скроллбар).
*   **JavaScript** (работа с API, DOM, асинхронные запросы).
